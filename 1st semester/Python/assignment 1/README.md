# Math Utilities & Geometric Calculations

A collection of Python functions solving various mathematical problems. This module focuses on functional definitions, avoiding redundancy, and using Python's operator module.

## Contents

### 1. Algebraic Functions
* **Rational Expressions:** Implementation of complex algebraic formulas (e.g., `f(x)`) using functional calls (`add`, `div`) rather than standard operators.
* **Euclidean Distance:** Calculation of vector magnitudes using `sqrt` and power functions.

### 2. Code Optimization (`fix_me`)
* **Refactoring:** Demonstrates the **DRY (Don't Repeat Yourself)** principle.
* **Geometry:** Reusable functions to calculate the Area and Perimeter of:
    * Circles
    * Isosceles Right Triangles

### 3. Recursive Patterns
* **`draw_number`:** A recursive function to visualize positive/negative integers using `+` and `-` characters without loops.

## Technical Concepts
* **Operator Module:** Using `add`, `mul`, `truediv`.
* **Variable Swapping:** Pythonic tuple unpacking `x, y = y, x`.
* **Refactoring:** Converting repetitive script code into modular functions.
