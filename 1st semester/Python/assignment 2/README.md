# Algorithms, Sequences & Recursion

This project explores fundamental algorithmic concepts in Python, focusing on functional programming paradigms, sequence summation, and list processing.

## Key Algorithms

### Functional Programming & Higher-Order Functions
* **Custom HOFs:** Implementation of logic similar to `map`, `filter`, and `reduce`.
* **`abacize`:** A function that transforms numerical operations into visual "bead" representations (abacus style).
* **`reverse_args`:** A decorator-style function that reverses the arguments of any given function.

### Sequence Analysis
* **`sum_sequence`:** A generic function to calculate the sum of the first *n* terms of any given mathematical sequence.
* **`paei_pi`:** Approximates the value of **Pi (π)** using an infinite series summation.
* **Recursive Math:** * `sum_squares`: Summing squares recursively.
    * `digit_sum`: Summing the digits of a number.

### Data Filtering
* **Prime Numbers:** An optimized algorithm (`primes_up_to`) using list comprehensions to generate prime numbers up to a limit.

## Technical Concepts
* **Recursion** vs **Iteration**.
* **Lambda Expressions**.
* **List Comprehensions**.
* **Functional Purity**.
