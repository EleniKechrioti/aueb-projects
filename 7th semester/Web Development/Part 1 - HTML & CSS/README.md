# HTML & CSS

## Description 
The first part of the website consists solely of static content, which is displayed upon opening each page in the web browser without requiring communication with a web server. The implementation is done using HTML5, CSS, and JavaScript, where JavaScript is only used for complex form validation rules.

> This section is developed in five sequential tasks, each covering different aspects such as structure and content, layout and styling, responsiveness, data input, and validation. Each task builds upon the previous one.

## Interact with Renthub
To explore the project, open the **index.html** page in your web browser. From the menu, navigate through the tasks (details provided below). To see the final version, visit **Exercise 5**, which integrates all previous tasks.

## Implementation Details 
This part of the project follows a structured development process, divided into five tasks:

- **Exercise 1**: Focuses on the use of semantic HTML elements. Classes are applied primarily to **div** elements to provide meaning rather than for styling purposes, which is addressed in later tasks.

- **Exercise 2**: Introduces CSS for styling elements. A basic multi-column layout is achieved using **float**. Some **flex** properties are used selectively but are not the main focus of this task.

- **Exercise 3**: Implements advanced layout techniques using **flex** and **grid**. All pages follow a three-column structure.
- **Exercise 4**: Focuses on responsiveness, utilizing media queries to optimize the layout for mobile devices, tablets, and desktops. The selection of breakpoints was based on industry best practices.

- **Exercise 5**: Completes the website with a sign-up form. Input validation is handled both through HTML properties and JavaScript. JavaScript is used specifically for cases where validation cannot be achieved through native HTML attributes.

 HTML and CSS files have been validated using the [Markup Validation Service](https://validator.w3.org/) and the [CSS Validation Service](https://jigsaw.w3.org/css-validator/).
