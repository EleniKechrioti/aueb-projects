# Advanced Methods in Software Engineering - Coursework

This repository contains the deliverables for the "Advanced Methods in Software Engineering" course. The work is divided into two main components: a theoretical research presentation and a practical software development project.

---

## 1. Bibliographic Presentation: Generative AI in Software Engineering
**Topic:** The impact, applications, and challenges of Generative AI (GenAI) across the Software Development Life Cycle (SDLC).

Based on a comprehensive review of recent literature (including IEEE Software publications), this presentation explores how GenAI is redefining the industry.

### Key Areas Covered:
* **SDLC Transformation:** How GenAI acts as a "Copilot" in design, coding (improving productivity by up to 55%), testing, and deployment.
* **Modern Code Review (MCR):** AI support in summarization, feedback provision, and explanation, while identifying current gaps in human-centric decision-making.
* **Test Data Generation:** Using LLMs to create realistic, privacy-compliant, and culturally literate "fakers".
* **Software Security Analysis (SSA):** Comparing GenAI with traditional static analysis tools and its role in code auditing and binary analysis.
* **Educational Impact:** A case study on UML modeling where AI serves as a catalyst for critical thinking and reflection.

## Overview
**FacilityGuard** manages physical security checkpoints in real-time. It processes access requests through a multi-stage security pipeline to ensure only authorized personnel access specific zones.

### Key Features
* **Security Pipeline:** Enforces Card Validation, **Anti-Passback** rules, and **Spatial Topology** checks.
* **Access Management:** Granular control over Users, Access Cards, Permissions, and Buildings.
* **Monitoring:** Real-time **Access Logs** and security **Alerts**.
