# Cybersecurity Governance and Technologies - Coursework

This repository explores the dual role of Artificial Intelligence (AI) in the cybersecurity landscape, analyzing how it functions as both a powerful defensive tool and a sophisticated offensive weapon.

---

## Project Topic: AI as a Double-Edged Sword
**Focus:** Enhancing and Bypassing Cybersecurity through Machine Learning (ML) and Deep Learning (DL).

### 1. Defensive AI: Enhancing Capabilities
Traditional security methods based on signatures often fail against modern threats. This project analyzes how AI shifts the defense strategy toward behavioral analysis.

* **Intrusion Detection Systems (IDS):** Using ML to identify anomalies and zero-day attacks by learning normal system behavior.
* **Malware Analysis:** Leveraging behavioral patterns to detect malicious software that traditional antivirus software might miss.
* **Workflow:** Analysis of the standard ML pipeline: Data Collection → Pre-processing → Model Learning → Detection & Reporting.

### 2. Offensive AI: Bypassing Defenses
The study also examines how attackers use AI to automate and scale their operations, creating a continuous "arms race" between defenders and hackers.

* **AI-Powered Attacks:** Use of AI for automated vulnerability discovery, high-volume phishing, and bypassing CAPTCHA systems.
* **Adversarial AI:** Techniques used to "trick" or evade existing AI-based security models.
* **Deepfakes & Social Engineering:** The use of generative models to create convincing fake content for social engineering attacks.

---

## Key Challenges & Limitations
Despite the advantages of AI in cybersecurity, the research identifies several critical challenges:
* **Data Quality:** AI models are only as good as the data used to train them.
* **Explainability (Black Box):** The difficulty in understanding the "why" behind an AI-driven security alert.
* **Human Oversight:** The ongoing necessity for human experts to manage false positives and complex decision-making.
